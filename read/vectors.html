৩ডি ভেক্টর

দুটি ভেক্টরের তিন অক্ষ বরাবর উপাংশ বদলাও। যোগ, ডট গুণ আর ক্রস গুণ কীভাবে তীরের আকারে ঘটে, ঘুরিয়ে দেখো।

৩ডিতে ঘুরিয়ে দেখো

খসড়া: এই লেখা এখনো শিক্ষকের যাচাই হয়নি। পাঠ্যবইয়ের সাথে মিলিয়ে নাও।

মূল ধারণা

ভেক্টরের মান ও দিক দুটোই আছে। ত্রিমাত্রিক জগতে প্রতিটি ভেক্টরকে x, y, z অক্ষ বরাবর তিনটি উপাংশে ভাগ করা যায়। যোগ করতে হলে অনুরূপ উপাংশ যোগ করতে হয়। ছবিতে B এর লেজ A এর মাথায় বসালে শুরু থেকে শেষ পর্যন্ত যে তীর পাওয়া যায়, সেটিই A + B। ডট গুণের ফল একটি স্কেলার: A·B = AB cos θ, যেখানে θ দুটি ভেক্টরের মধ্যবর্তী কোণ। এটাকে B এর ছায়া A এর ওপর গুণ A এর দৈর্ঘ্য হিসেবে ভাবা যায়। ক্রস গুণের ফল একটি ভেক্টর: মান AB sin θ, যা A ও B দিয়ে তৈরি সামান্তরিকের ক্ষেত্রফলের সমান, আর দিক A ও B উভয়ের লম্বে, ডান হাতের নিয়মে।

সূত্র

  • A + B = (Ax + Bx, Ay + By, Az + Bz)
  • A·B = AxBx + AyBy + AzBz = AB cos θ
  • |A×B| = AB sin θ

উদাহরণ

A = (3, 0, 0) এবং B = (0, 4, 0)। যোগ: A + B = (3, 4, 0), মান = √(9 + 16) = 5। ডট গুণ: 3×0 + 0×4 + 0×0 = 0, তাই ভেক্টর দুটি লম্ব। ক্রস গুণ: (0×0 − 0×4, 0×0 − 3×0, 3×4 − 0×0) = (0, 0, 12), মান ১২, আর দিক z অক্ষ বরাবর।

যে ভুলগুলো সাধারণত হয়

  • ডট গুণ আর ক্রস গুণ গুলিয়ে ফেলা: ডটের ফল স্কেলার, ক্রসের ফল ভেক্টর।
  • A×B = B×A ভাবা: আসলে A×B = −(B×A), ক্রম বদলালে দিক উল্টে যায়।
  • ভেক্টর যোগে শুধু মান যোগ করা: দিক হিসাবে না ধরলে ভুল ফল আসে।

নিজেকে যাচাই করো

1. A = (1, 2, 2) হলে |A| কত?
  1. 3
  2. 5
  3. 9
  4. √5

|A| = √(1² + 2² + 2²) = √9 = 3।

2. দুটি অশূন্য ভেক্টর পরস্পর লম্ব হলে কোনটি সত্য?
  1. A·B = 0
  2. A×B = 0
  3. A + B = 0
  4. |A| = |B|

A·B = AB cos 90° = 0। ক্রস গুণ শূন্য হয় সমান্তরাল হলে।

3. A×B এর দিক কোনটি?
  1. A এর দিকে
  2. B এর দিকে
  3. A ও B দুটিরই লম্ব দিকে
  4. A + B এর দিকে

A×B সবসময় A ও B যে তলে আছে তার লম্ব, দিক ডান হাতের নিয়মে।

প্রশ্নোত্তর

লম্ব ভেক্টরের ডট গুণ কত?

শূন্য, কারণ cos 90° = 0।

সমান্তরাল ভেক্টরের ক্রস গুণ কত?

শূন্য ভেক্টর, কারণ sin 0° = 0।
